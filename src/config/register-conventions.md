# Convenções de nomenclatura — Registro

| Padrão | Exemplo |
| :--- | :--- |
| `is` + substantivo | `isRegisterRequestPending` |
| `handle` + ação | `handleRegisterFormSubmit` |
| `set` + feedback | `setRegisterGlobalFeedback` |

Campos do formulário espelham `RegisterFormValues`: `user`, `name`, `lastname`, `birthday`, `email`, `password`.
