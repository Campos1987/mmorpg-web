# Portal MMORPG — Lineage II

Frontend web do portal da comunidade do servidor (Next.js 16, TypeScript, Tailwind CSS v4).

## Início rápido

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
```
